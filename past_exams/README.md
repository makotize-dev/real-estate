# past_exams — 実物の年度別過去問（ローカル保存専用）

R2以降の週末に解く**実物の宅建過去問**（令和元年〜令和7年）を保存するフォルダ。年度はファイル名で区別する（例：`令和3年_問題.pdf` / `令和3年_正解.pdf`）。

## ⚠️ 重要：公開リポジトリにコミットしない

- 過去問PDF等は RETIO 等の**著作権物**。このリポジトリは GitHub Pages で公開しているため、**問題・正解のファイルは push しない**。
- `.gitignore` で `*.pdf / *.jpg / *.png / *.zip` 等を除外済み。**実物ファイルはこのフォルダにローカル保存するだけ**でよい（git は無視する）。
- 追跡されるのは、この README と自作の**採点メモ（.md）**のみ。

## 使い方（実物過去問の運用・2026-07-19合意）

1. **日曜（2.5h）に自力で50問・2時間・時間厳守**で解く（本番の解き順で）。
2. 解答中、各問に**確信度マーク**：**○＝根拠（条文・理由）を言える／無印＝それ以外（復習対象）**の**1ビットだけ**。**🔴 2026-08-16 改定**＝旧「無印＝自信あり／△＝消去法／?＝勘」の3段階を廃止（下記）。
3. 自己採点し、**点数＋分野別＋「✗（誤答）＋△/?（あやしい正解）の問番号」**を Claude に共有。
4. Claude が論点解説＋e-Gov検証＋**法改正フィルタ**（古い年度で正解が変わる肢を警告）。誤答論点は自作○×に抽象化して exam_v6 バンクへ。
5. **復習対象＝誤答＋あやしい正解**（まぐれ正解を炙り出す）。理解の確認＝**4肢すべての根拠を言えるか**。

## 🔴 レビューの方式（2026-08-05 再改定）＝下の8/2版を上書きする

**8/2版（誤答＝ピンポイント・問題文の貼り付け不要）には2つの穴があった**（8/5にユーザーが指摘）。

1. **論点の同定をユーザーの理解に依存する**。1行の読み筋メモはユーザーの読みを通した情報なので、論点の取り違えがあればチェックも外れた条文に対して行われ、**誤った理解がそのまま残る**（8/3の「結論は合っているが理由が条文とずれている」＝問37ア・問40イは、4肢モードだから見えた）。
2. **未検証の肢が残る設計そのもの**。直近の失点は「選んだ肢の誤り」より**他の肢を見ていないこと**に集中している（8/2 問35＝肢の前半で止まる／8/4 問5＝1肢を○と決めて検算を止める／8/5 問18＝肢3が正しいと思い1・2・4を未検証）。

### 新方式（役割分担で網羅性を回復する）

| 誰が | 何を | どこで消費するか |
|---|---|---|
| **ユーザー** | **問題文を貼る**（誤答・あやしい正解とも）＋**4肢それぞれの○×と一言** | コピペ数十秒＋採点直後の1〜2分 |
| **Claude** | **4肢すべてを条文で確認**して〔条文番号＋一言〕の**根拠表**を作る。**収録チェック（study_notes にあるか）もここで Claude が条文番号で行う**＝論点の同定をユーザーに依存しない | Claude の作業時間（セッション時間を使わない）|
| **会話** | **ユーザーの判断と食い違った肢だけ**を深掘りする | セッション時間はここだけに使う |

**8/2版は〔貼り付けの手間〕と〔セッション時間〕を節約する代わりに〔検証の網羅性〕を落としていた。直近の失点は網羅性の側で起きているので、削る場所を入れ替えた。**4肢すべてを会話で扱うわけではないので、1問20〜25分には戻さない。

### 収録チェックの結果は3分岐で扱う

| 状態 | 意味 | 処理 |
|---|---|---|
| **未収録** | 学習していない | **肢の順を捨てて分野をブロックで通す**（条文の並びで骨格を一巡→問に戻る）。roadmap に枠があるか確認し、無ければ枠を決める |
| **収録済みだが想起できない** | 学習したが知識になっていない | 想起の訓練へ（exam_v6 に事例型で追加・再テスト） |
| **収録済みで想起もできる** | 当てはめの誤り | ピンポイントで誤った信念を条文で潰す＋**肢の間の整合の検算**を確認する |

**🔴 型分類は「問単位」でなく「肢単位」で行う（2026-08-30 決定）。**同じ問でも回によって落ちる肢が入れ替わるため、問単位だと効いたレビューまで「再発」に見える。**実測＝令和元年 問12**は、7/26は**肢4**（34条1項を留保句で誤判定）を落とし、8/29は**肢1**（借地と読み事業用定期借地＝公正証書必須と考えた）を落としている。**7/26のレビューは肢4には効いていた**（8/29に肢4は根拠つきで正解）。問単位で数えた8/29の集計〔レビュー消化24問→再発8問（33%）〕は、**肢単位では再発率がこれより低い**（未再計算）。**運用**＝収録チェックと3分岐の判定は**肢ごとに1行**で持ち、問単位の集計はその積み上げとして出す。

**この3つはどちらも埋める必要がある**（2026-08-05 ユーザー）。「失点＝読み方」と一括りにしない。**8/2に出した「失点は知識の穴でなく読み方」という結論は業法にしか当てはまらない**——法令制限は令和2年の16肢中13肢が未収録条文だった（`study_log/宿題.md` の法令制限 未収録一覧を参照）。

### 🔴 確信度マークの定義（2026-08-16 改定＝実物③から適用）＝**1ビットにする**

| 記号 | 意味 | 復習対象 |
|:--:|---|:--:|
| **○** | **根拠（条文・理由）を言えて選んだ**。これだけを積極的に書く | 誤答なら対象 |
| **無印** | **それ以外すべて**（消去法・勘・迷い・書き忘れ） | **対象** |

**廃止した2点と、その理由**

**①「無印＝自信あり」を廃止**＝無印は「何も書かない」状態なので、〔確信がある〕と〔面倒で書かなかった〕が同じ記号に潰れる。しかも旧定義では無印が復習対象から外れる側だったため、**漏れが常に危険側に倒れた**。実測でズレが2回。

- **2026-08-02**：無印誤答7問のうち**3問（問26・27・39）が実は消去法**。
- **2026-08-14**：無印**正解**4問（令和元年 問14・問49／令和2年 問49・50）が**実は勘**。無印正解は復習対象外なので、**この4問は7/26以降一度も復習対象に入っていなかった**。土地・建物は「正解しているので触らなくてよい分野」に見えて、実際は学習ゼロだった。

**②△と?の区別を廃止**（2026-08-16・ユーザーの提起）。区別の目的は「**知識が誤って固まっている問**と**知らないだけの問**の切り分け」だった（`過去問演習記録.md` 155行）が、

- その切り分けは**上記「新方式」の収録チェック**（Claude が条文番号で `study_notes` を当てて3分岐に振る）が担当しており、**論点の同定をユーザーに依存しない**と明文化済み。**△/? は同じ判定をユーザー側で二重に、しかも先に見積もる仕組み**だった。
- **その見積もりは実測で外れている**。令和元年で実際に付いた **? は問2の1つだけ**だが、8/14に**同年の問14・問49も勘だったと訂正**された＝**取りこぼしのほうが多い**。
- 8/14の失敗は知識でなく**マークを付ける規律**の失敗なので、解答中の判断を減らすほうが効く。

**失うもの＝「まったく手がかりがなかった」という感覚の記録。**必要なら**採点後に任意で番号を挙げてもらう**（解答中の負荷ゼロ）。なお**接触の感覚は強弱の指標にならない**ことが8/9に実測されている（日影＝`study_notes` に2か所収録済みなのに「学習していない気がする」）。

**副作用＝復習対象が増える。**これは許容する。**PDF抽出（pypdf）が使えるようになり、4肢すべての根拠表を作る作業が Claude 側に落ちた**ため（上記「新方式」の役割分担）、増える量はユーザーの負担にならない。

## レビューの方式（2026-08-02 改定・7/19基準の修正）＝**8/5版に上書きされた。経緯として残す**

7/19の「**理解の確認＝4肢すべての根拠を言えるか**」は、もともと**あやしい正解のまぐれを炙り出す**ための基準だった。**誤答に適用すると、すでに正しく判断できている肢まで追う**ことになる（1問20〜25分）。対象で分ける。

| 対象 | モード | 目安 |
|---|---|---|
| 誤答（読み筋が誤り）| **ピンポイント**＝誤った信念だけ条文で潰す。**問題文の貼り付け不要** | 5〜10分 |
| 誤答（読み筋は正しいのに外した）| 問題文が必要（8/2の問35型＝供託所は合っていて**届出が抜けていた**）| 15分 |
| 個数問題（ア〜エ）| 外した項だけ | 10分 |
| あやしい正解 | **4肢すべての根拠**（本来の適用先）| 20〜25分 |

- **1年度あたりのレビュー上限＝2h。** 優先順＝**誤答の積極的誤り → 個数問題 → あやしい正解 → 消去法の誤答**。**入り切らない分は失点の型①〜⑧に分類してバンクへ送るだけで条文には戻らない**（年度を重ねれば同じ論点に別の顔で再会するため）。
- **採点直後に「読み筋メモ」を取る**：誤答は「**なぜその肢を選んだか1行**」、あやしい正解は「**正解肢の根拠1行**（言えなければ『言えない』）」。これがトリアージ材料になり、**問題文を貼る必要がある問だけに絞れる**（8/2は問33がこれで問題文なしに潰れた）。
- **確信度マークの定義（厳格化）**：**無印＝積極的な根拠があって選んだ／△＝消去法で残った／?＝勘**。「他を切ったから残った」は、どれだけ確信があっても**△**。8/2は無印誤答7問のうち**3問（26・27・39）が実は消去法**だった。
- **〔訂正の経緯〕**2026-07-19 に決めた旧配分は「R2＝**平成30**・令和元・2・3・4／令和5・6（＋7）はR3に温存」だったが、**平成30年は手元に無い**（教材を確認せずに配分を書いていた）。この誤りのため W8模試・W9 の2枠に充てる年度が不足していたので、上表に組み直した。**8/1にユーザーの指摘で発覚。**
- **年度を増やさない方針（2026-08-01 判断）**：2016〜2018年を追加する案を検討したが見送った。理由＝①ボトルネックは問題数でなく**レビューの時間**（①だけで復習対象32問・6日で23問しか消化できずW6〜W8へ食い込み中）②2016〜2018は**2020年民法改正前**で、手元教材のような**改題（令和8年度法改正対応版）**がされていない素の問題では**正解が変わる肢**を含み、法改正フィルタの手間がレビュー時間をさらに圧迫する③盛土規制法・区分所有法・景表法の条ズレ等、**法令制限と免除は陳腐化が速く**、弱点の訓練に向かない。**穴を埋めるなら年度別より分野別**（年度別は「本番の運用力」を測る道具であって穴を埋める道具ではない）。
